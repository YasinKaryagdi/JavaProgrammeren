# Programmeren in Java 

## Wat is programmeren?
**Programmeren is je idee omzetten in instructies die een computer kan uitvoeren.**

Je hebt een probleem of een idee, bijvoorbeeld "ik wil dit jaar mijn kerstlampjes zelf programmeren, zodat ze van kleur veranderen wanneer ..." (vul zelf maar in!). Dat is een heel leuk idee!!! Maar een computer snapt dat niet vanzelf.... Jij moet precies uitleggen wat er moet gebeuren. Dit moet in een taal die de computer begrijpt, in een programmeertaal.

### Programmeren is meer dan coderen!
Programmeren is echt **NIET** gelijk aan coderen!!!!! Coderen is een belangrijk onderdeel van het programmeren, maar er zijn ook andere belangrijke onderdelen, namelijk: 

1. **Doel bepalen:** wat moet het programma doen?
2. **Een algoritme ontwerpen:** welke stappen moet de computer uitvoeren, en in welke volgorde moet dat?
3. **Coderen:** je schrijft die stappen op in een programmeertaal, bijv. Java.
4. **Evalueren:** je test of de code doet wat je wilde. Zo niet, dan ga je terug en verbeter je de code of pas je je algoritme aan.

In deze cursus gaan we **visueel programmeren** in Java. Aan het einde van deze curcus ben jij bekend met het programmeer process en bezit jij verschillende programmeer skills, zoals algoritmes ontwerpen en debuggen.

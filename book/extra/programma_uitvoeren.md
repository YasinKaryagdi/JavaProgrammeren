# Programma Schrijven en Uitvoeren
Misschien denk je nu, "Meneer, ik weet echt niet hoe ik moet beginnen...".

Dat is erg normaal!

Ik laat je hier zien wat de bedoeling is.

Let op in dit voorbeeld heb ik al een project en Class bestand. Heb je dat nog niet? Kijk naar [Java project aanmaken](project_aanmaken.md). Hier maken we een project met de naam `PrintOefening`

## Wat te doen

>**Let op!** Hier zit nog geen zelfgeschreven code!

We gaan nu code toevoegen en uitvoeren, wanneer je de volgende 3 stappen hebt uitgevoerd ziet het er zo uit:
```{figure} ../figures/voorbeeld_prog_uitvoeren.png
---
width: 100%
align: center
---

```

1. Wanneer we code schrijven stoppen we het in de main methode. **Let op!!** de code moet echt tussen de haakjes gestopt worden!!! het moet dus tussen de **{** en de **}** van main.
2. We klikken op de "run" knopje. Dat is een groen knopje bovenin.
3. We kijken naar het resultaat in de "console". Die zit vaak onderin.

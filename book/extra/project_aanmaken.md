# Nieuwe Java project aanmaken
Bij iedere opdracht moet je een nieuwe Java project aanmaken.
Wanneer je een project aanmaakt moet je eerst even kijken naar de opdracht naam, noem je project precies zo.

## Maak project genaamd "PrintOefening"
We nemen deze naam als voorbeeld omdat we hiermee aan de slag gaan in week 1.
```{figure} ../figures/proj_1.png
---
width: 100%
align: center
---
Begin linksboven bij "File", ga dan via "New" naar "Java Project"
```

```{figure} ../figures/proj_2.png
---
width: 100%
align: center
---
Verander de naam van je project. Check de JRE, zorg ervoor dat de juiste circels blauw zijn. Klink op "Finish".
```



## aanmaken bestand binnen project
Om daadwerkelijk te kunnen programmeren moet je nog een bestand aanmaken binnen het project. **Hou de naam overal hetzelfde!** Dus zowel van je **project**, als je **bestand binnen je project**!

In week 1-3 gaan we werken met een Class bestand. [Een Class bestand aanmaken.](class_bestand_aanmaken.md)

Daarna gaan we leren over visueel programmeren aan de hand van een JFrame. [Een JFrame bestand aanmaken.](JFrame_bestand_aanmaken.md)
